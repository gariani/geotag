# Scripts

## Buy Me a Coffee URL (optional)

To use your personal Buy Me a Coffee link without committing it:

1. Copy `local_run.sh.example` to `local_run.sh`
2. Edit `local_run.sh` and replace the URL with your profile
3. Run `./scripts/local_run.sh` instead of `flutter run`

`local_run.sh` is gitignored – your URL stays private.
